# Development Log and AI Disclosure

## Project

MedEZY Monitoring Score Lab — BMA5278 AI and Analytics in Business Practice.

## Work completed

- Audited the original seven-pillar weighted score.
- Identified the MAP failure case in which 180/60 mmHg could receive a perfect legacy BP score.
- Narrowed the intended-use population and renamed the output a monitoring score.
- Replaced unsupported unequal weights with transparent equal weighting.
- Added non-compensatory safety rules.
- Built a seeded synthetic-data generator.
- Added v1-versus-v2 evaluation and automated tests.
- Built an interactive React user interface and export workflow.
