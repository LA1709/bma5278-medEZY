# BMA5278 Assessment Mapping

## Technical implementation

- React and TypeScript application
- Modular scoring and safety-rule engine
- Seeded synthetic-data generation
- Batch evaluation and visualization
- CSV export
- Automated tests and CI workflow

## Application of course concepts

- Descriptive analytics: cohort and status distributions
- Predictive-model evaluation concepts: confusion matrix, accuracy and macro F1
- Decision support: score and non-compensatory safety rules
- Experimentation: v1-versus-v2 comparison on the same reproducible cohort
- Responsible AI: explicit intended use, transparency, failure analysis and limitations

## Innovation and creativity

The project does not simply display a score. It audits an AI-generated algorithm, demonstrates a concrete failure, redesigns the logic, and exposes an evaluation lab inside the same application.

## Business value

- Easier interpretation of fragmented monitoring inputs
- Transparent reasons behind every result
- Safer escalation of critical readings
- A reusable test harness before changing production scoring logic

## Communication

Use the app's three tabs as the presentation structure:

1. Calculator — solution demonstration
2. Simulation Lab — results and evaluation
3. Methodology — evidence, assumptions and limitations
